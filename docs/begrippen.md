# Begrippen

De termen uit de handreiking en uit de deltatabellen, kort uitgelegd. De volledige lijst
staat in bijlage A van de handreiking.

| Begrip | Betekenis |
|---|---|
| Beheerobject | Een object dat Rijkswaterstaat beheert, zoals een sluis, brug of gemaal |
| Element | Een functioneel onderdeel van een beheerobject |
| Bouwdeel | Een onderdeel van een element, het niveau waarop gebreken worden vastgesteld |
| Gebrek | Een waarneembare afwijking aan een bouwdeel |
| Gebreksoort | De indeling van gebreken naar aard, met een belang (gering, serieus, ernstig) |
| Faalwijze | De manier waarop een onderdeel zijn functie verliest |
| Falen | Een systeem kan zijn functie niet meer vervullen en voldoet niet aan de functionele eis |
| Functionele eis | Hoe goed een functie moet worden vervuld |
| Aspecteis | De kwaliteit waarmee de functie wordt geleverd, bijvoorbeeld beschikbaarheid |
| RAMSSHE€P | De elf aspecten waarop prestaties worden gesteld |
| Betrouwbaarheid | De kans dat een systeem gedurende een periode geen functieverlies vertoont |
| Beschikbaarheid | Het deel van de tijd dat een systeem zijn functie kan vervullen |
| FMECA | Failure mode, effect and criticality analysis: de kwalitatieve risicoanalyse |
| Foutenboom | Schema van combinaties van falen die tot de topgebeurtenis leiden |
| Risicomatrix | Matrix van kans tegen gevolg waarmee risico's worden geprioriteerd |
| Instandhoudingsplan (IHP) | Het plan met de maatregelen die uit de risicoanalyse volgen |
| p-IHP | Prestatiegestuurd instandhoudingsplan, gebaseerd op een kwantitatieve analyse |
| PO / TAO / CO | Periodiek, toestandsafhankelijk en correctief onderhoud |

!!! note "Nog aan te vullen"

    Deze lijst is een eerste selectie. Bijlage A van de handreiking bevat de volledige
    definities; die worden hier stap voor stap overgenomen.
