# Leidraad PRA

De *Handreiking prestatiegestuurde risicoanalyses (PRA)* van Rijkswaterstaat legt uit
hoe je van een beleidsdoel komt tot onderbouwde onderhoudsmaatregelen. De kern: je
bepaalt welke prestaties een systeem moet leveren, je brengt in beeld welke risico's
die prestaties bedreigen, en je kiest maatregelen die de risico's aanvaardbaar maken.

## De drie varianten

De handreiking onderscheidt drie varianten van de risicoanalyse, die elk horen bij een
variant van het instandhoudingsplan.

| Variant | Wanneer | Resultaat |
|---|---|---|
| Kwalitatieve objectrisicoanalyse | Voor het overgrote deel van de ruim 6.000 objecten | Een set maatregelen waarmee de kans op falen aanvaardbaar klein is |
| Kwantitatieve objectrisicoanalyse | Bij objecten met kwantitatieve eisen of een kritieke rol in het netwerk | Een set maatregelen waarmee aantoonbaar aan de prestatie-eisen wordt voldaan |
| Combinatie | Bij objecten waarvan alleen delen kritiek zijn | Kwantitatief waar het moet, kwalitatief waar het kan |
