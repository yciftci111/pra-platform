# Rekentools

Rekenbladen waarmee je de kwantitatieve kant van de risicoanalyse doorrekent: wat kost
instandhouding per jaar, hoe betrouwbaar is het systeem en hoe vaak is het niet
beschikbaar.

## Wat een rekentool wel en niet doet

Een rekentool vervangt de analyse niet. De decompositie, de faalwijzen en de
uitgangspunten komen uit de risicoanalyse; de tool rekent ze door en maakt zichtbaar
welke maatregel het meeste oplevert. Leg de uitgangspunten daarom altijd vast bij de
uitkomst.
